# 🚀 Quick Start - ML Boost Store

Panduan super cepat untuk mulai menggunakan website ini.

## ⚡ 3 Langkah Mulai

### 1️⃣ Ganti Nomor WhatsApp (WAJIB!)
```bash
# Buka file app/page.tsx
# Cari: 6281234567890
# Ganti dengan: nomor WhatsApp kamu
```

### 2️⃣ Jalankan Website
```bash
npm run dev
```
Buka: http://localhost:3000

### 3️⃣ Deploy (Gratis!)
```bash
# Push ke GitHub
git init
git add .
git commit -m "Initial commit"
git push

# Lalu deploy di vercel.com (connect GitHub)
```

## 💡 Tips Cepat

### Ganti Harga:
Cari `price:` di `app/page.tsx` → ubah angkanya

### Ganti Warna:
Edit `from-blue-900 via-purple-900` di `app/page.tsx`

### Tambah Paket:
Copy-paste satu paket, ganti isi, tambah `id` baru

## 🆘 Troubleshooting Cepat

**Error saat npm run dev?**
```bash
rm -rf node_modules
npm install
npm run dev
```

**Build error?**
```bash
rm -rf .next
npm run build
```

**Port 3000 sudah dipakai?**
```bash
npm run dev -- -p 3001
```
